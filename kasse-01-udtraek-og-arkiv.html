Udtrukket 3. august 2026 fra my.zettle.com (organisation Spillestedet Paletten, org-id 68133682) forud for skiftet til OnlinePOS.

1. Den vigtigste begrænsning: Zettle gemmer kun 3 år

Zettles API afviser enhver forespørgsel på salgshistorik før 3. august 2023:

`` "Cannot query purchase history data before 2023-08-03" ``

Det gælder både API og rapportmodulet i portalen. Salgsdata fra før september 2023 findes ikke længere — hverken hos jer eller hos Zettle. Det kan ikke genskabes.

Konsekvens: udtrækket her er Palettens fulde bevarede POS-historik. Arkivet skal behandles som regnskabsmateriale og opbevares i 5 år, jf. bogføringsloven og kravene i 03-rapporteringskrav.md (bilagsopbevaring 5 år).

Sekundær konsekvens: vent ikke med at lukke Zettle-kontoen. Så længe abonnementet består, kan udtrækket gentages. Lukkes kontoen, forsvinder også de sidste 3 år.

3. Hvor ligger det

Arkiv (rådata — opbevares, redigeres ikke)

`` OneDrive/Claude-projekter/Spillestedet Paletten/Zettle-arkiv/ ├── raadata-json/ 5 filer, 70 MB — komplet API-svar, uændret ├── transaktioner-csv/ salgslinjer.csv (43.548 rk.) + kvitteringer.csv (32.232 rk.) └── udtraek-csv/ produktliste, kasse-layout og salg pr. produktnavn ``

udtraek-csv/ ligger på OneDrive og ikke i git, fordi filerne indeholder navne på medlemmer og sponsorer (kasse-layoutet har én knap pr. medlem).

Arbejdsdata (i dette repo)

`` kasse/ ├── csv/ aggregerede udtræk uden persondata — varegrupper, terminaler, sortiment └── tools/ scripts der genskaber alle CSV'er fra rådata ``

Rådata ligger ikke i git (70 MB). CSV'erne kan altid genskabes:

``bash python3 kasse/tools/build_csv.py # flade transaktions-CSV'er python3 kasse/tools/build_analyse.py # varegruppe-analyse + OnlinePOS-import ``

Begge scripts læser fra raw/ — kopiér raadata-json/ dertil først.

4. Sådan blev det hentet

Zettle har ingen samlet eksportfunktion. Portalens egne API-kald blev genbrugt med sessionens adgangstoken:

DataEndpoint
Salgpurchase.izettle.com/purchases/v2 (sideopdelt, 1.000 pr. kald)
Produkterproducts.izettle.com/organizations/self/products/v2
Kasse-layoutlayouts.izettle.com/organizations/self/layouts
Terminalercash-register.izettle.com/cash-registers/all
Salgsstedersites.zettle.com/sites/v1
Lagerinventory.izettle.com/v3/stock

Skal udtrækket gentages, er fremgangsmåden dokumenteret i tools/README.md.
